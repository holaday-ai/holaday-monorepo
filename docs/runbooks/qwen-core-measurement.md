# 千问核心文本测量准备（不是发布门禁）

## 当前状态

`apps/orchestrator/scripts/qwen-core-measurement.ts` 提供显式调用的诊断函数 `runQwenCoreMeasurement`。它不由生产应用导入，没有自动运行的 CLI，不载入环境文件或 PM2，不读取进程环境，不创建任务或改动数据库、额度和配置。本轮仅验证工具，**没有运行真实千问测量**。

原有 `qwen-core-gold.json` 包含预先写入的 `actual` 结果；原静态合同中的分数只能证明固定测试的判分逻辑。新工具不读取这些结果，使用真实确定性核验器、语义核验器、区域运行时和建议生成器，从本次调用的响应计算聚合值。现有发布门禁、阈值、灰度配置和固定版本控制均不改变。

## 调用与权限

- 不传 `transport` 时直接返回 `blocked/NETWORK_NOT_AUTHORIZED`，不联网。
- `fixture` 模式必须提供模拟网络函数，可传入测试时钟；报告始终标为 `mode: fixture`。
- `provider` 模式必须显式设置 `allowProviderCalls: true`，该参数仅表达调用者意图，**不替代人工授权**。它不接受模拟网络或时钟，不读取或推断账号身份。
- 调用者必须提供已经合法核对的运行时配置、精确合成账号和持久化区域。工具只接受唯一合成白名单，继承现有 lane/适配器/同区凭据和端点校验；缺少任何条件直接停止，不修改配置来让测试运行。
- 当前发布控制更新尚未获批，不得通过本工具绕过暂停、修改固定 SHA 或开启灰度。真实调用只能在既有批准条件齐备后由受控调用方执行；本次没有增加生产执行入口。

仅本地模拟网络的验证命令：

```bash
pnpm --filter @holaday/orchestrator exec vitest run scripts/qwen-core-measurement.test.ts --maxWorkers=2 --minWorkers=1
```

## 测量内容与预算

固定的 8 个合成候选样本涵盖有依据的答复、保留未知信息、遗漏、与材料矛盾、答非所问、材料中的提示注入、安全结论冲突和未取得证据的引用。没有真实用户材料，不接受任意外部样本输入。

先运行真实确定性核验；失败的样本单独计数，不消耗语义模型调用。其余通过 `verifyWithLlm` 调用 `verify_strict`，保留 pass/warn/reject/unavailable。此诊断不运行自动修复、不持久化，不替代完整任务终态/UI 验收。

可选短调用使用真实 `generateSuggestions`、`suggestions` lane 和 `fast` 模型，保留请求约束继承与解析。它不是计划、抓取、生成或所有模型的统一延迟基准。

- 默认不采集短调用；`shortCallSamples` 可为 0–20。
- 全程串行，最多 27 次调用、120 秒；调用数和时长都可下调，不能上调。
- 语义调用最长 15 秒，建议调用最长 4 秒，都受剩余总时长约束且零重试。达到预算保留 `partial`、停止原因和已经完成的覆盖量。
- 20 个短调用全部产生可用建议时，用 nearest-rank（排序后第 19 个）计算描述性 p95。少于 20、覆盖未完成、存在不可用或无效计时均不输出 p95，不能只删除失败请求后计算“成功样本 p95”。20 是本诊断的显示约束，不是新的发布批准标准。

## 如何读报告

- `completed` 仅表示本次诊断流程执行完，不表示质量通过。
- `labelProvenance: synthetic_unreviewed`：候选标签由合成样本编写者提出，没有真人审定。即使真实调用，也必须保留该标识。
- `semanticSevereIssueRecall`、`semanticCorrectAnswerFalseRejectionRate` 仅在**实际进入语义核验**的样本中计算；分母为零时返回 null，确定性拦截另行计数。它们不是 Task14 的整体核验指标，不可直接映射到生产预检。
- `structuredOutputValidity` 是所有已尝试语义调用中得到可解析语义结果的比例。网络失败、超时和非法结构均计入不可用，因此它是端到端可用结构比例，不是排除网络错误后的纯 JSON 格式指标。
- `deterministicFailToPass` 来自真实确定性输出及单调合并，不是文件中预写的 before/after。
- `p95Ms` 仅描述当前固定建议工作负载，不覆盖生产端到端延迟，也不是足够代表用户分布的统计结论。
- `releaseEvidence` 永远为 false；此工具不输出阈值 pass/fail、不生成生产 preflight 输入、不改动任何既有门禁。
- 报告只返回模式、区域、预算与覆盖、计数、比率、时长等聚合信息，不返回输入、答案、URL、账号、请求/回复标识、密钥或原始错误。

仍需：合成材料与候选标签的人工复核、充分且有代表性的真实同区测量、生产聚合观测、真实 UI 引用/刷新/计划建议验收，以及原上线手册中的全部发布条件。不得用本工具的测试通过代替这些证据。
