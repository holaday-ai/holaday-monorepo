## 变更摘要：v0.1 → v0.2

这轮调整基于你 PDF 上的批注和"其它 6 条"新要求，**有六处是基础性变化**，需要你先扫一眼确认没误解：

1. **技术栈与 OrangeBench 彻底独立**（原 §5.3）
   - 不再"尽量复用 OrangeBench"，而是**干净另起**，只保留数据库 schema 格式相同（便于未来潜在互通）
   - 这让 HOLA DAY 在架构、依赖、发布节奏上完全自由，也让它在融资/剥离时更干净

2. **极简哲学，删除"角色卡片"这个显式 UI**（原 §4.3）
   - **Agent 智能识别用户意图**，不要求用户选角色
   - 用户只在**首次使用的引导流程**和**设置-职业身份**里输入一次"我是做什么工作的"
   - 对话入口是唯一入口，像 Claude 一样极简

3. **同时删除"场景任务次入口"**
   - 不做一键任务、不做快捷卡片——进一步统一到对话入口

4. **场景 D 作为唯一长期协同路径**（原 §9.3）
   - OrangeBench 演化为 Agent / Skill 市场
   - 第三方开发者在 OrangeBench 发布，HOLA DAY 用户订阅——这是最有延展性的一条路

5. **定位从"企业优先"调整为"员工-企业双轨"**
   - 原 v0.1 说的是"企业先行"——你的批注明确指出"**员工才是事情最多的用户，老板不买单他们自己也要能买**"
   - v0.2 产品和定价都按双轨设计：个人员工能自掏腰包、企业能集采

6. **新增四块内容**（全部基于你的"其它 6 条"）
   - §7：目标用户画像 × 10 个岗位 + **股市分析专章**（合规红线：只分析不建议）
   - §8.6：自动装机流程
   - §8.7：无人值守 / 突破 continue 限制
   - §9：多端形态（Chrome / Desktop / Android 平板 APP / 微信）
   - §12：工程协作与部署责任链
