# FIX-LAYOUT-1 完成报告

已在 `codex/fix-sidebar-toggle` 续修，合并交付到同一个草稿 [PR #268](https://github.com/holaday-ai/holaday-monorepo/pull/268)。未合并、未部署、未连接服务器，未改后端、生产配置或密钥。

## 复现与修复

- **浏览器工具条被遮挡，已复现并修复。** 公共 `.hd-shell-topbar` 的不透明背景覆盖了工作区顶部 76px；它允许鼠标穿透，因此旧的点击命中检测没有发现。任务工作区改为使用自身工具条，其他页面仍保留吸顶背景。
- **分栏约束已统一。** 对话区原来固定 `lg:min-width:560px`，与紧凑布局分配的 320px 下限不一致。现在对话区与浏览器分栏共享同一套下限，工作区由可收缩的 flex 子项填满剩余高度；首页内容也允许按可用宽度收缩。浏览器画面继续使用原有等比包含缩放。
- **今日能量额外裁切，已复现并修复。** 1100px 窗口扣除侧栏后，卡片不足以容纳三列，但原断点只判断窗口宽度。现在仅补给卡片按自身容器宽度切换为两列或单列；不改颜色、插画和动效。
- **首页横向溢出、底部约 80px 留白：当前基线未复现。** 修复前 1200×1200 实测主区及侧栏已满高，首页未越界；本轮没有把未复现的现象写成已确认根因。修复后完整尺寸矩阵再次验证这两项。

## 审计能力变化与边界

- 默认新增 `1200×1000`、`1366×768`；原三个 `×960` 视口及其基线文件名兼容保留。
- 新增文档/容器内部横向溢出、外壳/主区/侧栏未撑满高度检测，以及不透明顶栏遮挡浏览器工具条检测；有真实 DOM/CSS 的正反例。
- 支持 `UI_AUDIT_VIEWPORTS` 指定宽高；报告与截图名称区分相同宽度的不同高度。
- 本轮使用 `--layout-only`，检查路由就绪、运行时/网络错误、布局和任务状态，跳过完整控件遍历及像素基线比对。原始审计仍为 **exit 1 / failed**，原因是保留的四条筛选/覆盖声明，**不是完整发布门禁通过**。
- 新尺寸的全路由像素基线未创建或覆盖，留给第 2 层发布前视觉审阅。本次按测试政策未跑全量前后端测试或完整交互审计。
- 数据、浏览器画面及接口均来自本地种子环境；真实生成、真实网站、退款和行情数据不在本轮验收范围。字体/品牌远程资源按原审计规则离线替代。
