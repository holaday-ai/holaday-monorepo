# 确认稿还原核对 — 2026-10-06

**当前结论：第二轮已补齐主要前端结构和动效缺口，但尚未达到所有真实状态逐帧一致的验收标准。** 本报告区分已实现、已浏览器核验和未覆盖状态，不作为发布依据。

分支：`codex/approved-ui-fidelity`，基于 `811dd1e6`。本轮只修改前端与核对文档；未修改后端、数据库、迁移、部署脚本或服务器，未发布。此前 PR #240 的代码审核通过不等于确认稿还原通过。

## 对照基准与核对方法

- 以原会话最终确认的 `sidebar-preview/` 当前 HTML、CSS、JS、素材为准，包含后续修改；不使用早期截图代替最终文件。
- 今日能量以 `energy-design/DESIGN.md` 和三张确认图为准，保留原插画。
- 品牌色按后续明确指令使用 `#FF0061`。本轮浏览器读取主按钮实际颜色为 `rgb(255, 0, 97)`。
- 源文件路径及 127 份参考文件的 SHA-256 见 [reference-manifest.json](reference-manifest.json)。参考目录未修改。
- 新任务位置配对为 1280×720；第二轮其他桌面截图为 1280×1165，窄屏检查为 390×844。实现端是隔离的本地 React 样例，连接真实组件、模拟查询、拒绝写操作，没有连接生产后台。
- 文件、任务、项目数量来自本地样例。股市缺少实时数据，显示空态/降级态。截图不是线上真实数据与权限验证，也不是新生成的作品。

## 第二轮验证与限制

- 全量前端：272 个文件，270 通过、2 失败；2579 项中 **2576 通过、3 项既有基线失败，0 新增失败**。退出码 1，不能称全量通过。
- 三项失败：`task-hub-state.test.ts` 的日期/错误格式测试；`energy-progress.test.ts` 的存储不可用时内存进度、移除收藏不删除完成历史两项，均为既有日期相关基线。
- 新增行为验证：模式切换保留草稿、素材/每次授权约束、文件库PDF身份、项目归属失败重试不重建任务、股市设置与附件契约；保留团队权限/验收表格/看板和计划焦点/未保存保护测试。
- 最终 ESLint、两份 TypeScript 配置与 Vite 生产构建均通过，构建退出码0；存在大于700KB chunk 的体积提示。
- 390px 窄屏下股市、口播及规划编辑器没有页面横向溢出；规划抽屉稳定宽366px，左右12px。未覆盖所有移动端弹窗组合。
- 所有浏览器证据使用本地模拟查询、拒绝写操作；未完成已登录生产账号的真实生成/计费、上传删除、退款重试、浏览器流视频或实时行情验收。
- 本轮只涉及前端和文档，无后端、数据库、迁移、部署脚本或服务器变更；未推送、合并、部署。

## 剩余出入与后续验收

1. 项目参考资料缺少项目与文件的真实关联接口；保留空态和文件库入口，不能用假文件补图。指定成员可看且管理员都可看的权限功能仍属后续后端工作，本轮未实现。
2. 图片“使用示例”、动作复刻示例还需可用的授权素材与上传身份衔接；不能假装已完成可生成样例。
3. 真实行情/图表/股市详情、上传后报价、生成中/失败/退款重试/结果等状态需已登录集成环境逐项验收。现有测试证明相关契约没有新增失败，不证明全部视觉状态一致。
4. 尚未做所有二级弹窗、各角色/套餐、移动端组合及逐帧录像误差验收。当前完成的是主要结构与指定动画参数的还原。
5. 无最终确认稿的页面仍按上面的单独清单报告；不以共用外壳改色代表整页还原完成。
