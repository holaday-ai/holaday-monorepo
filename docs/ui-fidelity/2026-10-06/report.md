# 确认稿还原核对 — 2026-10-06

**当前结论：未达到“所有页面与动效完全一致”，不能作为视觉验收完成或发布依据。** 本报告记录已经修复的部分、仍存在的差异，以及没有覆盖的状态。不是发布报告。

分支：`codex/approved-ui-fidelity`，基于 `811dd1e6`。本轮只修改前端与核对文档；未修改后端、数据库、迁移、部署脚本或服务器，未发布。此前 PR #240 的代码审核通过不等于确认稿还原通过。

## 对照基准与核对方法

- 以原会话最终确认的 `sidebar-preview/` 当前 HTML、CSS、JS、素材为准，包含后续修改；不使用早期截图代替最终文件。
- 今日能量以 `energy-design/DESIGN.md` 和三张确认图为准，保留原插画。
- 品牌色按后续明确指令使用 `#FF0061`。本轮浏览器读取主按钮实际颜色为 `rgb(255, 0, 97)`。
- 源文件路径及 127 份参考文件的 SHA-256 见 [reference-manifest.json](reference-manifest.json)。参考目录未修改。
- 桌面对照为 1280×720；窄屏检查为 390×844。实现端是隔离的本地 React 样例，连接真实组件、模拟查询、拒绝写操作，没有连接生产后台。
- 文件、任务、项目数量来自本地样例。股市缺少实时数据，显示空态/降级态。截图不是线上真实数据与权限验证，也不是新生成的作品。

## 验证与限制

- 全量前端：270 个测试文件，268 通过、2 失败；2572 项中 **2569 通过、3 项既有基线失败，0 新增失败**。测试进程退出码为 1，不能写成“全量通过”。
- 三项失败：`task-hub-state.test.ts` 的日期/错误格式测试；`energy-progress.test.ts` 的存储不可用时内存进度、移除收藏不删除完成历史两项。
- 全量之后的图片、视频、规划、侧栏、tooltip 改动已跑针对性回归；图片最后一批25项通过。新增参考资料加载竞态、保留文件身份、补给手动开始的行为测试通过。
- ESLint 通过；TypeScript 两份配置通过；Vite 生产构建通过。存在大于700KB chunk 的构建提示，未在本轮解决。
- `git diff --check` 通过。未修改 `apps/api`、`packages`、`scripts`。
- 窄屏稳定状态：文件列表和视频页均 viewport/body/root=390px，视频背景3px溢出已修复。其他主要页面完成窄屏抽查，未覆盖所有弹窗组合。
- 未进行已登录生产账号操作、真实生成/计费、生产上传删除、退款重试、浏览器流视频或实时行情验收。
