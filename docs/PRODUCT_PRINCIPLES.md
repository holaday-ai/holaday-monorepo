# HOLA DAY 产品核心定位

> 这是 HOLA DAY 的核心定位文档。所有后续开发决策以此为准。

---

## 一句话

HOLA DAY 是用户的 **meta-agent**：它替用户操作任何网站，也替用户操作任何 AI 工具。

---

## 核心原则

### 1. 用户零学习成本

每次有新产品上市（Claude Design、ChatGPT Canvas、Figma AI、任何新工具），用户不需要花精力去学怎么用。HOLA DAY 掌握这些工具的强大功能，替用户实现需求。

用户只需要说"我要什么"，不需要知道"怎么做"或"用什么工具做"。

### 2. Agent 控制 Agent

如果目标网站自带 AI agent（比如网站内置的聊天机器人、AI 助手），HOLA DAY 优先评估：

- 那个 agent 够聪明 → **直接控制它完成任务**（更快更稳）
- 那个 agent 不行 → **HOLA DAY 自己操作页面完成**
- 选择最快最稳的路线，不拘泥于某一种方式

### 3. 后台独立运行

用户点 Run 后可以做任何事。agent **不抢焦点、不要求配合、不依赖窗口可见**。任务完成后通知用户看结果。

### 4. 全能操作

目标是在任何用户能打开的网站上，尽可能完成用户想要的所有操作。不只是"看一看抓数据"，而是真正的执行：填表、提交、下载、配置、管理。

---

## 这意味着什么

- HOLA DAY 的 Skill 体系不只是"爬取某网站数据"，而是"**精通某个工具的全部能力**"
- Planner（Opus）在规划时要评估：**目标网站有没有内置 AI？用它还是自己做更快？**
- 每个 Skill 应该包含**对目标网站 AI 能力的认知和操作策略**
