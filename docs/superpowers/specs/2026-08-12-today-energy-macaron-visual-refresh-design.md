# HOLA DAY 今日能量下半页马卡龙视觉升级设计

## 1. 决策与目标

本轮选择“马卡龙能量乐园”方向，只升级 `/cosmic` 页面中已经上线的新增区域：

1. 星座深度补给站；
2. 星座区内的“继续往下逛”；
3. 页面底部的“再逛一会”。

上半页的能量英雄区、三类玩法入口、今日能量成长和星座能量卡保持现有布局、图片、文案层级和交互逻辑不变。目标是让下半页延续上半页的 3D 插画、明亮马卡龙配色、圆润卡片和轻盈互动感，解决当前内容主要由同构文字卡片组成、停留感不足的问题。

成功标准：

- 新增区域在不减少内容和入口的前提下，能靠图像、图标、色彩和布局快速区分内容；
- 页面上下两部分看起来属于同一套视觉系统；
- 用户切换星座周期、继续探索和更换内容时能获得轻量反馈；
- 动效不抢阅读注意力，并完整支持减少动态效果设置；
- 桌面和移动端都不出现图片裁切、文字溢出或操作目标缩小。

## 2. 保留范围与非目标

必须保留：

- 当前 DivineAPI 与本地降级数据流；
- 今日、本周、本月、本年的周期切换；
- 六维星座内容、幸运线索、七日趋势及相应空态；
- 十二星座排行、星座预览、抽卡和轻测试入口；
- “再来一组”的去重逻辑、内容总量和事件上报；
- 现有语义结构、键盘操作、焦点样式和错误提示。

本轮不做：

- 不修改上半页；
- 不新增 API、数据库或运营后台；
- 不改变内容推荐和去重算法；
- 不重新设计抽卡、测试、小游戏的体验容器；
- 不引入视频、广告、积分经济或新的内容类别；
- 不用装饰性图片代替真实按钮、标题和正文。

## 3. 统一视觉语言

页面继续使用现有能量域设计变量，并补齐下半页所需的语义层：

- 奶油白：主要内容底色；
- 蜜桃粉：幸运签、抽卡和温暖提示；
- 薰衣草紫：星座、主选中态和深度内容；
- 天空蓝：知识、放松和理性提示；
- 薄荷绿：测试、关系和身心内容；
- 珊瑚红：主操作、重要反馈和当前焦点，不大面积铺底。

主容器继续使用 26–32px 圆角，内容卡使用 16–22px 圆角。阴影保持低透明度紫灰色，不增加深色描边。标题颜色保持 `--energy-ink`，辅助文字保持现有灰紫色，不能为了“活泼”降低正文对比度。

图标统一使用仓库已有的 Lucide 线性图标，尺寸、描边和圆角容器保持一致。方向箭头使用正式图标，不使用文本字符。图片只使用已经认可的 `/public/energy` 资产和当前星座对应的十二星座图像，避免混入股票编辑图或另一种插画风格。

## 4. 星座深度补给站

### 4.1 星座视觉舞台

现有标题区改成两列舞台：

- 左侧保留标题、说明、数据来源和周期标签；
- 右侧显示当前星座的大号圆形图像，使用与上半页星座卡相同的图像来源；
- 图像周围放置 2–3 个小型信息泡泡，优先展示幸运色、顺手时段和当前周期；
- 使用 `Sparkles`、`Clock3`、`Palette` 等图标帮助识别，不增加新的长文。

图像使用完整可见的 `object-fit: contain` 或与圆形资产匹配的 `cover`，不能出现主体被裁切。周期切换时只更新当前内容和信息泡泡，不重建整个页面。

### 4.2 周期与主内容

今日、本周、本月、本年的标签继续保持横向切换，但选中态增加柔和白色滑块和轻微上浮。月度的本月、下月控件保持二级层级。

主内容区保留摘要和刷新按钮。摘要下方的六维内容改成带图标的马卡龙信息单元：

- 每个维度拥有稳定图标；
- 图标置于 34–38px 的柔色圆角容器中；
- 工作、个人、健康等维度使用交替的蜜桃、天空蓝、薄荷和薰衣草底色；
- 正文仍为代码原生文本，默认展示三项，原有“展开全部六项”继续工作。

幸运色使用真实色块；顺手时段使用小型时间轨道；七日趋势继续使用原有数据可视化。无趋势数据时保持诚实空态，不用伪造图形填充。

## 5. “继续往下逛”互动入口

四个普通文字按钮升级为四个“能量入口”，仍使用原有操作：

1. 十二星座排行：紫色，排行图标；
2. 换个星座看看：天空蓝，交换或轨道图标；
3. 抽一张相关能量牌：蜜桃粉，星光或卡牌图标；
4. 测个相关主题：薄荷绿，测试图标。

每个入口包含图标容器、主标签、一句不超过 12 个汉字的副提示和方向箭头。入口在桌面端四列展示，在中等宽度两列，在手机端单列。点击后的排行、星座选择器及体验弹层保持现有功能和焦点行为。

## 6. “再逛一会”内容花园

### 6.1 桌面布局

每批仍展示六条内容，但从六张相同卡片改为两层节奏：

- 第一行两张图片主卡，承载本批前两条内容；
- 第二行四张图标轻卡，承载剩余四条内容；
- 卡片顺序仍由现有推荐结果决定，不改变内容算法。

主卡包含稳定比例的图片区域、类别、预计时长、标题、两到三行摘要和清晰操作。轻卡使用大号彩色图标、标题、短摘要和箭头操作，避免为了统一而强行塞入小图。

图片按类别映射：

- 放松：`recharge-island.jpg`；
- 幸运签：`energy-capsules.jpg`；
- 星座知识：当前星座图像；
- 关系问答、投票、测试推荐：`quick-test.jpg`；
- 抽卡推荐：`tarot-cards.jpg`；
- 小游戏推荐：`mini-game.jpg`。

图片容器使用类别对应的马卡龙底色，图片以完整展示为优先；仅允许轻微缩放，不允许为了铺满而裁掉主体。

### 6.2 移动布局

手机端主卡和轻卡全部变为单列。主卡图片采用横向 4:3 或接近 16:10 的稳定比例；轻卡保持紧凑，但触控目标不小于 44×44px。标题最多自然换行两行，摘要不通过极小字号压缩。

### 6.3 内容打开反馈

“打开这个内容”保留现有事件和目标逻辑。点击后使用图标、文字和底色共同显示已打开状态，不能只改变文案。打开抽卡、测试、小游戏或星座目标时，仍进入现有目标位置或体验容器。

## 7. 动效系统

动效只服务于层级、切换和反馈：

- 星座图像以 6–9 秒周期轻微上下漂浮；
- 周围星光使用不同延迟缓慢闪烁；
- 周期切换时内容使用 180–260ms 的淡入和 6–10px 位移；
- 六维信息按顺序出现，间隔不超过 40ms；
- 能量入口悬停时上浮 2–3px，图标轻微旋转或摆动，箭头向前移动；
- 内容卡悬停时上浮最多 4px，图片缩放不超过 1.035；
- “再来一组”触发 240–320ms 的交错替换，刷新图标只旋转一周；
- 不使用持续抖动、强烈弹跳、无限快速闪烁或大面积视差。

在 `prefers-reduced-motion: reduce` 下关闭漂浮、闪烁、交错入场、旋转和缩放，只保留即时的颜色与边框状态变化。

## 8. 组件边界

现有 `EnergyHome` 继续只负责编排，不引入新的页面级状态。

建议的定向调整：

- `AstrologyWorld.tsx`：加入星座视觉舞台和四个能量入口的展示结构；
- `AstrologyDimensionGrid.tsx`：加入稳定的维度图标映射和视觉容器；
- `LuckyInsights.tsx`：在不改变数据结构的前提下加强色块、时段和趋势表达；
- `EnergyExploreFeed.tsx`：根据批次位置渲染图片主卡或图标轻卡，并集中管理类别视觉映射；
- `energy.css`：补充下半页颜色、布局、动效和响应式样式；
- 测试文件：验证内容数量、入口语义、图片映射、切换状态和减少动态效果约束。

类别与维度的视觉元数据应定义为小型常量映射，不在 JSX 中复制条件分支。视觉映射不参与推荐和业务判断。

## 9. 错误与降级

- 星座图像加载失败：退回现有星座图标容器，不能显示破图；
- 内容图片加载失败：保留类别图标和马卡龙底色，卡片仍可操作；
- Provider 请求失败：继续显示现有本地提示和来源说明；
- 换一组返回空内容：继续显示现有已浏览完成空态；
- 动态内容较长：允许卡片自然增高，不遮挡操作按钮。

## 10. 验收与测试

自动检查：

- 能量域相关组件测试全部通过；
- Web Workbench 类型检查、目标测试和构建通过；
- `git diff --check` 通过；
- 图片路径和十二星座图像映射测试通过；
- 现有来源诚实性测试继续通过。

浏览器检查：

1. `/cosmic` 正常渲染且无框架错误覆盖层；
2. 桌面首屏保持不变，滚动到下半页后视觉语言连续；
3. 星座图像完整、信息泡泡不遮挡标题和控件；
4. 今日、本周、本月、本年切换后内容、选中态和动画正确；
5. 展开六维、查看排行、换星座、抽卡和测试入口可操作；
6. “再来一组”仍展示六条不重复内容，并出现交错替换反馈；
7. 至少打开一个图片主卡和一个图标轻卡，状态反馈正确；
8. 桌面与手机宽度无横向溢出、主体裁切和过小触控目标；
9. 控制台无相关错误或警告；
10. 减少动态效果设置下没有持续动画。

## 11. 上线边界

本轮只形成新的前端提交和 PR。合并与部署继续分别等待明确授权。上线后重点观察下半页内容打开率、“再来一组”使用率、星座周期切换率和体验入口点击率；本轮不新增埋点，仅使用已有事件判断变化。
