# 视频创作场景工作台规格

## 目标

将 `/video` 从“先配置模型参数”的表单页改为“先选择想完成的视频，再补充重点”的场景化创作工作台，使用户一眼理解 HOLA DAY 能做什么，同时不破坏普通视频、动作复刻、IP 人物视频的真实提交、报价、授权、历史和结果链路。

## 视觉目标

- 桌面目标尺寸：`1440 x 1024`
- 视觉语言：暖白底、轻亮马卡龙辅助色、HOLA DAY 粉色主行动、真实场景图片、低噪声边框和阴影。

## 产品结构

1. 页面标题使用“视频创作”。
2. 首屏问题使用“这次想完成哪种视频？”，提供四个带真实图片的场景入口：
   - 产品高光短片：普通视频。
   - 生活方式 Vlog：普通视频。
   - 复刻一段动作：复刻视频。
   - IP 人物口播：IP 人物视频。
3. 普通视频默认展示两列工作台：左侧为所选场景的三段式镜头规划，右侧依次为创作重点、素材、参考风格、AI 编排说明、生成设置和主行动。
4. 模型、风格、时长、比例、画质等技术参数保留，但降级到可展开的“生成设置”。
5. 复刻和 IP 场景继续使用现有真实上传、授权、估价及提交表单；场景卡负责切换对应链路。
6. 历史作品降低失效占位的视觉体量，保留真实失效说明、筛选、置顶、下载和结果入口。
7. 商业许可未就绪时，“继续剪辑”只显示“即将开放”，不得表现为可用功能。

## 交互与无障碍

- 场景选择使用单选语义，键盘可聚焦，选中态同时通过边框、勾选图标和 `aria-pressed` 表达。
- 切换场景不得自动提交、上传或扣费。
- 普通视频的预置文案仅在用户主动选择场景时应用；用户已经编辑的内容不得在无操作时被覆盖。
- 所有仅图标按钮必须同时提供 `aria-label` 和原生 `title`。
- `prefers-reduced-motion` 下禁用位移动效。

## 验收标准

- 四个场景到现有三种视频类型的映射有自动化测试。
- 普通视频的场景预置、生成设置摘要及真实提交参数保持可测试。
- 复刻、IP 授权与报价逻辑的既有测试全部通过。
- 同一视口的参考图与本地实现完成组合对比，`design-qa.md` 的 `final result` 为 `passed`。
- Web 测试、类型检查、构建、控件 tooltip 规则通过。
- 生产 `/video` 可访问，场景切换和设置展开可用；不进行付费生成。
