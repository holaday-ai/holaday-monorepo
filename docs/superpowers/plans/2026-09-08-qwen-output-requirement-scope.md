# 输出需求与数量归属修复

## 目标与边界

修复内容选题的数量与后续电商背景词组合后被误判成商品清单的问题。
共享分类器同时服务执行合约与最终审核，不绕过任一校验，不删除原始任务和用户补充。
保留真实商品的数量、价格、链接、排序要求；不按工作流或“不采购”全量豁免。
不更改模型路由、凭据、额度、支付、账户注销、部署配置。
