## 部署前仍须解决

1. 审核相对实际运行版本的全部历史差异，不能只审本次提交；服务器 checkout 不等于已证明运行 SHA。
2. 2026-09-25 只读预检已区分两条启动路径：线上当前未带受控池启动元数据，普通启动不会调用 native loader。Node 22.20.0 不满足新受控池 loader 的 22.x 门槛（至少 22.23.2），但不能把该门槛笼统视为本地 Chrome 路径必须先完成整套池扩建。受控池还缺原生产物验证及开放准入接入；不得关闭门槛部署，也不能声称升级 Node 即可完成。
3. 实际 schema 已只读核对：0059 的三个执行身份字段缺失；0060 的四个新增字段缺失，五个用量/费用字段仍为非空零默认值。当前数据库未发现名称含 `migrat` 的表；仓库 numbered runner 会执行 SQL，不是只读版本探针。部署脚本的代码回滚不会撤销已执行 SQL；未知费用仍应为 NULL，不允许改零掩盖缺口。
4. 明确维护、扩展分发和灰度范围后，再按后端→前端→兼容扩展切换；不能直接执行默认指向旧分支的 `deploy-current.sh`。
5. 当前 selected-Chrome 是明确选定的单页执行与文件交付路径；多页、上传、Canvas 视觉兜底、此路径的 playbook/AgentBay/Firecrawl 联动及代表性同题成功率仍未验收。本次没有缩减用户的最终产品目标，也没有宣布完整浏览器大项已上线就绪。
