## 关键实现要点

### Popup 防连点
- `inFlight: Record<taskId, action>`：同一 task 同一时刻只允许一个 in-flight HTTP。
- `controlTask` / `confirm` 两个 fetch 入口都加了：`if (inFlight[taskId]) return` + `setInFlight(...)` + `finally { setInFlight(drop) }`。
- TaskCard 收 `busy: boolean`；Pause / Resume / Confirm / Skip / Reject / 批量按钮都 `disabled={busy}`；主按钮文案 `"处理中…"` 覆盖。
- Vite build 51 modules 清洁。

### `xueqiu-portfolio-digest`
- 第二个金融 skill，与 eastmoney-news-digest 互补：一个做"板块宏观要闻 + 股吧热帖"，一个做"自选股个股 + 当日动态 + 雪球讨论区"。
- 同样**登录态继承**：入口 goto 后若落 `xueqiu.com/login` 或自选列表为空 → awaiting_user。
- 合规红线与 eastmoney 完全相同（只分析不建议，不出买/卖/目标价/加仓/满仓等词；战略 v0.2 §7.3）。
- 数据延时诚实：manifest caveats 显式标 `dataDelayMin: 15`，结果 JSON 里也带，commander system prompt 后续（W3）会把这个作为硬约束。
- 付费帖安全：标 `paywalled: true` 后跳过，不尝试解锁。
- 限流合规：同任务不重复 goto 同一股代码，上限 20 只 × 3 条新闻 × 3 条讨论。
