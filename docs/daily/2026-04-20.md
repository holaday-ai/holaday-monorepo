## Skill catalogue 注入

### 注入形式

```
<system-prompt base>                 [cache_control: ephemeral]

<catalogue block>                    [cache_control: ephemeral]
User occupation tag: ecommerce-customer-service

Available Skills (slug — one-line description). Reference by slug only;
full SKILL.md is fetched on demand via SkillLoader, not sent here.
- taobao-qianniu-inbox — 汇总过去 24 小时未回复的千牛客服消息，并按买家分组输出摘要。
```

两个 text block 各自有独立 cache breakpoint，base prompt 不受 catalogue 变化影响。

### 路由查询

```sql
SELECT slug, description, occupation_tag FROM skills
WHERE status='active' AND (occupation_tag IS NULL OR occupation_tag = :occupation)
```

- 无 occupation → 只拉 `occupation_tag IS NULL` 的通用 skill。
- 有 occupation → 通用 + 该职业的。
- 未来可扩 per-user 订阅表，现在靠 skill 表的字段就够。

### 空 catalogue 保护

无 skill 无 occupation 时**不**生成第二个 text block，避免一个"空字符串 cache write"的意外写入（测试覆盖）。

## Paused 状态全景

### 状态机

```
executing ─err×N─▶ executing ─err─▶ paused(retries_exhausted)
executing ─pause─▶ paused(user)
executing ─quota─▶ paused(quota_exceeded)
paused ─resume─▶ executing（re-dispatch current step）
paused ─cancel─▶ cancelled
```

### MAX_STEP_RETRIES=1

Phase 0 设置 = 1 次额外重试，即："首错 → 再试一次 → 再错 → 升为 paused(retries_exhausted)"。
- 理由：多数 UI 抖动一次重试就稳；超过一次基本是 selector 坏了 / 被挡住 / 逻辑错，需要人介入。
- 改成 2 或 3 只需动一行（`const MAX_STEP_RETRIES = N`）。

### 持久化字段

- `tasks.pause_reason VARCHAR(32) NULL`
- `task_steps.retry_count INT NOT NULL DEFAULT 0`
- Migration: `drizzle/0002_paused_state.sql`。

### 新 tRPC 接口

- `tasks.pause({taskId})` → `{taskId, status, pauseReason}` / 412 on bad state
- `tasks.resume({taskId})` → `{taskId, status}` / 412 on bad state

两者都走 `applyControlTransition(prev, next)`（新方法，不走 step-result 路径），并通过 `broadcastToUser(userId, msg)` 把 `server.task.control` 推给该 user 所有已连 WS 客户端（多 tab 场景全覆盖）。

### Restart recovery 覆盖 paused

- `rehydrateInFlight` 现在返回 `pauseReason` 字段。
- WS 鉴权成功后：`awaiting_user` → 重发 `server.user.confirm`；`paused` → 重发 `server.task.control command: 'pause' reason: ...`。同时 drain 桶避免多 tab 重复弹窗。

### 事件日志

| 事件 | 触发 |
|---|---|
| `step.retry` | 首错后同一步重试 |
| `task.paused` | 任一触发器进入 paused |
| `task.resumed` | paused → executing |
